# Geometry (Crop, Rotate, Geometry)

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/crop-rotate-geometry.html (fetched 2026-09-16)

## Crop

| Control | Range | Description |
|---|---|---|
| Crop overlay handles (drag) | n/a | Adjusts the crop boundary |
| Aspect | categorical (ratio list) | Sets the crop's aspect ratio |
| Rotate Aspect Ratio | button | Rotates the crop overlay 90° |
| Constrain Aspect Ratio (lock icon) | on/off | Locked = aspect ratio fixed; unlocked = adjust freely |
| Pan/zoom while cropping | hold spacebar | Pan and zoom the image while the crop overlay is active |
| Straighten | unstated | Adjusts overall image alignment/rotation |
| Crop Overlay guide | categorical (grid types) | Dropdown menu of compositional guide overlays |
| Constrain Crop | on/off | Restricts the crop overlay to the visible image area |

## Rotate & Flip

| Control | Range | Description |
|---|---|---|
| Rotate Left / Right | 90° steps | Rotates the photo's orientation |
| Flip Vertical | on/off | Mirrors the photo vertically |
| Flip Horizontal | on/off | Mirrors the photo horizontally |

## Geometry (perspective)

| Control | Range | Description |
|---|---|---|
| Upright mode | Auto Upright / Guided Upright | Auto: one-click automatic perspective correction. Guided: draw 2+ guides on vertical/horizontal lines for manual correction |
| Transform: Distortion | unstated | Adjusts distortion introduced during capture |
| Transform: Vertical | unstated | Straightens/tilts vertical lines |
| Transform: Horizontal | unstated | Adjusts horizontal lines |
| Transform: Rotate | unstated | Rotates the image clockwise/anticlockwise |
| Transform: Aspect | unstated | Defines the aspect ratio of the entire image |
| Transform: Scale | unstated | Zooms in/out without changing the aspect ratio |
| Transform: X Offset | unstated | Moves the image left/right |
| Transform: Y Offset | unstated | Moves the image up/down |
| Constrain Crop | on/off | Restricts the crop overlay to the visible image area after geometry edits |

## Interactions

- Tools and Geometry settings are excluded by default from the "Default" preset in the Copy/Paste Edit Settings dialog — see `copy-paste-edits.md`.
- Perspective correction (Guided/Auto Upright, Transform) commonly leaves transparent/empty edges; see `extend-generative-expand.md` to fill them.
