## Presets panel

| Control | Range | Description |
|---|---|---|
| Amount | 0–200 | Controls the intensity of the applied preset |
| Favorite (star icon) | on/off | Marks a preset as Favorite; Favorites group is synced to Lightroom on mobile |
| Preset group visibility (Manage) | show/hide per group | Per-device setting for which preset groups appear in the panel (not synced across devices) |
| View mode | List / Grid / Large thumbnails | Display style for browsing presets |
| Navigate presets | Up/Down arrow keys | Steps through presets while previewing on the photo in Detail view |

## Preset categories

| Category | Description |
|---|---|
| Recommended | Adobe-Sensei–generated presets adapted to the specific photo's content, evolving as the AI learns; carousel filters: Subtle, Strong, B&W, Cool, Warm, Dark, Bright, Cinematic, HDR |
| Premium | Curated presets updated with each Lightroom release. Includes **Adaptive** (Portrait, Sky, Subject, Landscape, Blur Background) and **Portraits** (Deep Skin, Medium Skin, Light Skin, Black & White, Edgy, Group) |
| Subject | Themed looks: Concerts, Food, Landscape, Lifestyle, Travel, Travel II, Urban Architecture |
| Yours | User-created and saved presets, including the Favorites group |

## Interactions

- The Amount slider here is the preset-intensity equivalent of the Profile panel's Amount slider (`profiles.md`).
- Adaptive Presets for Subject and Sky (Premium group) can be applied together with AI **Select Subject** / **Select Sky** masks — see `masking.md`.
