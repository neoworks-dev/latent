# Effects

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html#effects (fetched 2026-09-16)

## Effects panel

| Control | Range | Description |
|---|---|---|
| Texture | unstated (left = smoothen, right = accentuate) | Smoothens or accentuates textured detail; does not change color or tonality |
| Clarity | unstated (left = soften, right = increase) | Changes contrast around object edges |
| Dehaze | unstated (left = add haze, right = remove haze) | Adds simulated haze or removes existing haze |
| Vignette (Amount) | unstated | Makes the outer edges of the photo lighter or darker |
| Vignette: Feather | unstated | Lower = less softening between vignette and surrounding pixels; higher = more softening |
| Vignette: Midpoint | unstated | Lower = Amount adjustment applied to a larger area away from corners; higher = restricted closer to corners |
| Vignette: Roundness | unstated | Lower = more oval vignette; higher = more circular vignette |
| Vignette: Highlights | unstated | Controls highlight contrast preserved when Amount is negative; suited to photos with small bright highlights (candles, lamps) |

## Interactions

- The Vignette sub-sliders (Feather, Midpoint, Roundness, Highlights) only take effect once the main Vignette Amount is non-zero.
- Texture, Clarity, and Dehaze also appear as local-adjustment sliders inside Masking — see `masking.md`.
