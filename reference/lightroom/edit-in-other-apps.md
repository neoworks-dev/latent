# Edit in Other Apps

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-in-other-apps.html (fetched 2026-09-16 — page content was mostly site-chrome/navigation in the fetched proxy output; workflow described below cross-confirmed via WebSearch summary of the same page)

Not a slider/control — a round-trip external-editor workflow: send a photo from Lightroom to any third-party application for additional editing, and it automatically returns to Lightroom when finished.

## Workflow

| Action | Description |
|---|---|
| Edit In (right-click in Grid or Detail view) | Sends the photo to a chosen external application for editing |
| (automatic) return | The edited result returns to Lightroom automatically once the external app's save/close completes |
