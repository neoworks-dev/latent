# Light

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html#light (fetched 2026-09-16)

Using the slider controls in the Light panel, you adjust the overall tonal range of the image.

## Light panel

| Control | Range | Description |
|---|---|---|
| Auto | button | Automatically sets Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Saturation, and Vibrance to what Lightroom judges as the best edit (Saturation/Vibrance are color sliders adjusted by this same button — see `color.md`) |
| Exposure | unstated | Overall image brightness |
| Contrast | unstated | Tonal contrast, mainly affecting midtones |
| Highlights | unstated | Recovers/adjusts detail in overexposed highlight areas |
| Shadows | unstated | Recovers/adjusts detail in underexposed shadow areas |
| Whites | unstated | Sets the white point |
| Blacks | unstated | Sets the black point |

## Histogram interaction

- Specific regions of the Histogram map to the tone sliders above. Moving the pointer over a Histogram region highlights the affected area on the photo and the corresponding slider.
- Dragging directly in the Histogram adjusts the corresponding slider (Exposure, Highlights, Shadows, Whites, or Blacks) and updates the image live.

## Clipping indicators

| Control | Range | Description |
|---|---|---|
| Shadow clipping indicator (upper-left of Histogram) | on/off | When illuminated, shows shadow-clipped pixels as a blue overlay on click |
| Highlight clipping indicator (upper-right of Histogram) | on/off | When illuminated, shows highlight-clipped pixels as a red overlay on click |
| Show Clipping in Histogram | on/off | Right-click (Win) / Cmd-click (Mac) the Histogram to toggle the clipping indicators themselves |

### Keyboard shortcuts

| Shortcut | Action |
|---|---|
| J | Toggle shadow/highlight clipping overlays on the photo |

## Interactions

- See `curves.md` for the Tone Curve and Point Curve, which sit inside the Light panel and provide finer tonal/contrast control than the sliders above.
- See `masking.md` for the same set of tonal sliders (Exposure, Contrast, Highlights, Shadows, Whites, Blacks, plus more) applied locally to a mask instead of globally.
