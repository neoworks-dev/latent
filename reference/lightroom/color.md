# Color

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html#color (fetched 2026-09-16)

The Color panel groups three tools: Color Mixer (this file), Color Grading (`color-grading.md`), and Point Color (`point-color.md`).

## Color Mixer

Gives targeted control over colors sampled directly from the image, letting you adjust hue, saturation, or luminance for the colors directly under the pointer.

| Control | Range | Description |
|---|---|---|
| Setting select | Hue / Saturation / Luminance | Chooses which property the drag gesture adjusts |
| Drag on photo | left = decrease, right = increase | Move the pointer over a color, then drag horizontally to adjust the selected setting for that color |

## Global color sliders referenced by Light > Auto

The Light panel's Auto button (see `light.md`) also sets **Saturation** and **Vibrance**. This page names these two sliders but does not individually describe their range or effect elsewhere in the fetched content.

| Control | Range | Description |
|---|---|---|
| Saturation | unstated | Not individually described on this page; included in the Auto tonal/color adjustment set |
| Vibrance | unstated | Not individually described on this page; included in the Auto tonal/color adjustment set |

## Interactions

- Point Color (`point-color.md`) can be combined with Masking (`masking.md`) for localized single-color refinement without affecting overall image vibrancy.
- Color Grading (`color-grading.md`) works on shadow/midtone/highlight tint rather than a single sampled color.
