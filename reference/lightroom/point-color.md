# Point Color

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html#color (fetched 2026-09-16, "Fine-tune individual color in a photo with Point Color" subsection)

Lets you select and refine an individual color in a photo across Hue, Saturation, and Luminance, for precise, detailed color refinements. Available starting with the October 2023 release of Lightroom. Can be combined with Masking for localized control over specific colors without changing the vibrancy of the entire image.

## Point Color panel

| Control | Range | Description |
|---|---|---|
| Color picker / Color Field | n/a (color selector) | Selects a specific color in the photo (or from the Color Field); creates a swatch next to the picker. Up to 8 swatches can be stored at once |
| Hue Shift | unstated | Shifts the color tone of the selected range along the color spectrum |
| Saturation Shift | unstated | Controls intensity of the selected color range (more vivid ↔ more muted) |
| Luminance Shift | unstated | Changes brightness of the selected color range (lighter ↔ darker) |
| Variance | unstated | How closely matching colors are pulled toward (left) or pushed away from (right) the sampled color; useful for refining skin tones or subtle color details |
| Hue Range | unstated | Range slider restricting which hues are affected |
| Saturation Range | unstated | Range slider restricting which saturation levels are affected |
| Luminance Range | unstated | Range slider restricting which luminance levels are affected |
| Visualize Range | on/off | Shows only the areas affected by the current color selection |
| Reset | button / double-click on the slider | Resets slider(s) to default |

## Interactions

- Combine with Masking (`masking.md`) to restrict a Point Color edit to a specific region of the photo.
- Distinct from the Color Mixer (`color.md`), which adjusts colors by dragging directly on the image rather than sampling and refining one stored swatch at a time.
