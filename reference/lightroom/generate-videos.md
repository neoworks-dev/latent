# Generate Videos from Images

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/generate-videos-from-images.html (fetched 2026-09-16)

Not a photo edit operation — a generative image-to-video feature ("Generate Video"). Included for completeness since it is listed in the Lightroom desktop "Edit photos" table of contents.

## Generate Video dialog (Photo > Generate Video, or right-click > Generate Video)

| Control | Range | Description |
|---|---|---|
| Model | Firefly Video / Google Veo 3.1 / Google Veo 3.1 Fast | Selects the generative video model (partner models consume credits per their own rules) |
| Aspect ratio | categorical | Output width:height ratio |
| Resolution | categorical | Output video quality/definition |
| Duration | seconds (categorical choices) | Output video length |
| Prompt | free text, or presets (Slow pan, Subtle motion, Hyperlapse) | Describes the desired motion/video content; Subtle motion and Hyperlapse are AI-generated prompt presets |
| Create stack | on/off | Groups the source photo and generated video together (Cloud only) |
| Generate | button | Produces the video; progress shown in the header bar; consumes generative credits |
