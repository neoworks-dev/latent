# Versions

Source: https://helpx.adobe.com/lightroom/desktop/edit-photos/edit-photos.html#versions (fetched 2026-09-16)

Versions let you quickly view and compare different edits made to the same photo. Available from the sidebar since the June 2023 release of Lightroom desktop (v6.4).

## Versions panel

| Control | Range | Description |
|---|---|---|
| Named tab | n/a | Holds user-created, manually saved Versions |
| Auto tab | n/a | Automatically-saved Versions, one produced per editing session |
| Create Version | button + name field | Saves the current edit state as a new Named Version |
| Hover preview | n/a | Hovering a Version (Named or Auto) previews it live on the photo |
| Rename (three-dot menu) | n/a | Renames a Named Version |
| Delete (three-dot menu) | n/a | Deletes a Version |
| Save as Named Version | menu action (on an Auto version) | Promotes an Auto Version into the Named tab |
| Export with these settings | menu action | Exports the photo using that specific Version's edit state |

## Interactions

- A Version is effectively a saved snapshot of the full op-stack (every panel in this directory) at a point in time.
